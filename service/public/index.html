Add to Home Screen

Add a Still Home icon to open this companion from your phone.

iPhone or iPad

Open this page in Safari. Tap Share → Add to Home Screen, turn on Open as Web App if shown, then tap Add.

Android

Open this page in Chrome. Tap the ⋮ menu → Add to Home screen, then follow the prompts. It may instead say Install and create shortcut → Create shortcut.

Remember this phone before adding the icon. On iOS 17.2 or later, Safari can carry the connection into the new Home Screen app. If it asks to pair once, use a fresh code from your TV.

No app store needed. Keep your TV on with Still Home running and use the same trusted home Wi-Fi. This local HTTP page needs a live TV connection; full app installation may not be offered. If your TV’s address changes, open its new pairing link and add the icon again.
